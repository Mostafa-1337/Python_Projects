# Wuzzuf Project Version-2


## Description

- 80 or more python job on wuzzuf website.

- It extracts the job title, company name, company location, link of job, how long will you work and job posted.

## Features

- Get results from 10 pages

- Export to xlsx file

- Colors and style by openpyxl

## Technologies used

- Python

- Requests 

- BeautifulSoup4

- pandas

- openpyxl

## How to Run

 Write in VS terminal :

pip(or pip3) install -r requirements.txt
