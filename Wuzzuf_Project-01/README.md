#### A Simple Project With Python Requests and BeautifulSoup4.



* ###### It gets results about python job on wuzzuf website and upload to csv file.



* ###### It extracts the job title, company name, company location, link of job, how long will you work and job posted.







#### What I used in this projects:



* ###### Python:



\-To import libraries.

\-I used For Loop to create a list from rows and columns.

\-File handling to save results to csv file.



* ###### Requests:



\-To get server response(it was 200).



* ###### BeautifulSoup4:



\-To get html of website.

\-To find html tags and results from his attributes.



* ###### CSV:



\-To save results rows and columns.



* ###### Zip Longest:



\-To unpack html attributes
